# 云端模拟控制台（开发验证）

这个原型固定连接模拟小车，不显示车载画面，也不会控制实车或发射。可选用独立虚拟设备连接灵矽，网页通过手机麦克风说话、由手机播放回复；云端设备已绑定且与真实平台握手，真实手机语音往返仍待测试。它仅监听 `127.0.0.1`；如用于 HTTPS 代理测试，需显式配置 `--https-origin https://对应域名`，并由代理提供额外鉴权和限流，不能把回环服务直接公开。

在运行 Python 的机器上进入 `linx-client/`，安装 `requirements.txt` 后执行：

```bash
export CAR_DEMO_TOKEN="$(python3 -c 'import secrets; print(secrets.token_urlsafe(32))')"
printf '%s\n' "$CAR_DEMO_TOKEN"   # 自己输入网页时使用；不要提交仓库或发给其他人
python -m linx_client.cloud_demo
```

打开本机 `http://127.0.0.1:18765/`，输入刚生成的密码。服务不读取终端输入，可以在无交互终端里运行；按 Ctrl-C 关闭。测试服务器时，可先在自己电脑执行 `ssh -L 18765:127.0.0.1:18765 <服务器别名>`，再从同一台电脑访问该地址。不要把这个隧道绑定到公网地址。

按住方向键时模拟小车通过现有 `TankExecutor` 接收限速后的短时动作；松开、页面失焦或连接断开会发送或执行停车。这个测试无法证明真实网络丢包、车辆看门狗、实际摄像头、手机浏览器或灵矽语音可用。正式公网版本仍需设计 HTTPS、用户认证与限流、车载网关认证、指令时效和去重、断线停车及安全验证。

## 已配置的云端模拟站点

2026-10-30 已在 `ssh volcyun` 对应的服务器配置 [car.vibemill.top](https://car.vibemill.top/)。Cloudflare 新增独立 A 记录，使用 DNS only；服务器新增专用 Nginx 配置、Certbot 证书及续期钩子、独立 systemd 服务和 Python 虚拟环境。模板在 `deploy/cloud-demo/`，不包含凭据。现有站点的配置文件未修改；Nginx 配置检查通过后已平滑重载。

网页有两道验证，使用同一个随机密码：浏览器弹窗用户名为 `car`，打开页面后再次输入同一密码。密码保存在服务器的 root 私有目录，不要提交仓库或在聊天中发送；可由服务器管理员在自己的终端执行下面的命令查看：

```bash
ssh volcyun 'cat /etc/cyberbrick-cloud-demo/password'
```

查看服务状态和模拟动作日志：

```bash
ssh volcyun 'systemctl status cyberbrick-cloud-demo --no-pager'
ssh volcyun 'journalctl -u cyberbrick-cloud-demo -n 30 --no-pager'
```

未绑定时页面会显示独立云端虚拟设备的 6 位激活码；在[灵矽智控台](https://xrobo.qiniu.com/)的相应智能体「设备管理」添加设备并填入激活码。当前设备已绑定且服务端观察到平台握手；页面连接成功后可点「启用语音」并允许麦克风权限，按住「按住说话」发话，松开发送静音等待回复。页面同时只允许一位控制者，已有控制者时不要抢占；灵矽文字转写和回复也可能出现在服务器服务日志中。这里用的是云端新建的虚拟设备，不会覆盖电脑上的原身份；当前工具只操作模拟小车。

## 当前公网访问故障与本机测试

2026-10-30 用户反馈公网域名在电脑上报 `ERR_CONNECTION_CLOSED`，并确认域名未备案。当前外部 HTTP 请求被转向火山引擎拦截地址，HTTPS 连接被重置；服务器本机服务和证书验证正常。备案问题是可能原因，具体拦截原因尚需火山引擎确认；本机默认 DNS 另有 NXDOMAIN，而多个公共 DNS 已解析成功。手机公网访问尚未恢复。

这台 Mac 已建立仅监听本机的 SSH 隧道，可在同一台电脑打开 `http://127.0.0.1:18765/`，输入上面命令读取到的控制密码。隧道不使用公网域名，也不显示 Nginx 的用户名密码弹窗；网络断开后可能需要重新建立。若隧道已断开且本机端口未被其他程序占用，在本机终端执行：

```bash
ssh -f -N -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -o ServerAliveCountMax=3 -L 127.0.0.1:18765:127.0.0.1:18765 volcyun
```

2026-10-30 已通过隧道验证登录，以及桌面 Chrome 的模拟录音触发真实灵矽转写事件、回复文本和 PCM 音频；尚未验证用户的实际麦克风、物理扬声器或手机。长期公网使用需先请火山引擎确认拦截原因并按要求完成备案或接入；外部 HTTP 证书续期路径也被拦截，恢复后需重新验证。

证书当前有效期至 2027-01-28；Certbot 定时器已启用，部署时本证书的续期模拟和重载钩子测试曾通过，当前外部拦截出现后尚未重新验证。服务器本机监听 `127.0.0.1:18765`，设计上公网仅经 HTTPS 代理访问，Nginx 加了账号密码和请求限流，页面 WebSocket 还有独立的密码和来源校验。云端身份文件由 systemd 私有状态目录保存、权限 600；不能复制进仓库。由于目前没有真实车载网关，**不能把这个演示的验证等同于实车断线保护或语音、视觉已完成**。
