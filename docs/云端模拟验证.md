# 云端模拟控制台（开发验证）

**2026-11-01 更新**：本文记录早期模拟验证。当前腾讯云站点已显式启用实车模式，手机网页语音已改为点击开始、再次点击结束；用户已确认拔掉 USB 后语音让履带转动和停下。详情及实测范围见 [小车直连云端](云端直连实车.md)；本地运行不加 `--real-car` 时仍为模拟模式。

这个原型默认连接模拟小车，不显示车载画面，也不会控制实车或发射。可选用独立虚拟设备连接灵矽，网页通过手机麦克风说话、由手机播放回复；云端设备已绑定且与真实平台握手，用户已确认手机能听到语音回复。它仅监听 `127.0.0.1`；如用于 HTTPS 代理测试，需显式配置 `--https-origin https://对应域名`，并由代理提供额外鉴权和限流，不能把回环服务直接公开。

## 腾讯云站点的早期模拟验证

2026-11-01 确认 `ssh tencentyun` 对应服务器上已有同一个云端模拟服务，且腾讯云公网入口为 [小车云端控制测试](https://110.40.227.30/)。页面受浏览器账号密码和网页控制密码两层验证保护；用户名为 `car`，两处使用同一密码。服务器管理员可在自己的电脑终端自行查看密码，不要提交仓库或在聊天中发送：

```bash
ssh tencentyun 'sudo cat /etc/cyberbrick-cloud-demo/password'
```

进入网页后输入控制密码并点击「连接」，再启用语音并按住说话。模拟阶段已从 Mac 公网验证 HTTPS 证书、网页及 WebSocket 认证；用户已确认手机启用语音后能听到回复。该站点现在已切换为实车模式，发射锁定。IP 证书为短期证书，当前证书有效至 2026-11-06 16:49（北京时间）；续期定时器 active/enabled，但本次未验证下一次实际续期。

火山云原副本目前停止且禁用。两台服务器使用相同的灵矽设备身份，**不能同时运行**：后连接的客户端会把先前连接挤下线。

在运行 Python 的机器上进入 `linx-client/`，安装 `requirements.txt` 后执行：

```bash
export CAR_DEMO_TOKEN="$(python3 -c 'import secrets; print(secrets.token_urlsafe(32))')"
printf '%s\n' "$CAR_DEMO_TOKEN"   # 自己输入网页时使用；不要提交仓库或发给其他人
python -m linx_client.cloud_demo
```

打开本机 `http://127.0.0.1:18765/`，输入刚生成的密码。服务不读取终端输入，可以在无交互终端里运行；按 Ctrl-C 关闭。测试服务器时，可先在自己电脑执行 `ssh -L 18765:127.0.0.1:18765 <服务器别名>`，再从同一台电脑访问该地址。不要把这个隧道绑定到公网地址。

模拟模式下，按住方向键时模拟小车通过现有 `TankExecutor` 接收限速后的短时动作；松开、页面失焦或连接断开会发送或执行停车。模拟测试无法证明实车断网停车；实车实现和验证范围见 [小车直连云端](云端直连实车.md)。

## 火山云站点（历史，当前停止）

2026-10-30 已在 `ssh volcyun` 对应的服务器配置 [car.vibemill.top](https://car.vibemill.top/)。Cloudflare 新增独立 A 记录，使用 DNS only；服务器新增专用 Nginx 配置、Certbot 证书及续期钩子、独立 systemd 服务和 Python 虚拟环境。模板在 `deploy/cloud-demo/`，不包含凭据。现有站点的配置文件未修改；Nginx 配置检查通过后已平滑重载。

网页有两道验证，使用同一个随机密码：浏览器弹窗用户名为 `car`，打开页面后再次输入同一密码。密码保存在服务器的 root 私有目录，不要提交仓库或在聊天中发送；可由服务器管理员在自己的终端执行下面的命令查看：

```bash
ssh volcyun 'cat /etc/cyberbrick-cloud-demo/password'
```

查看服务状态和模拟动作日志：

```bash
ssh volcyun 'systemctl status cyberbrick-cloud-demo --no-pager'
ssh volcyun 'journalctl -u cyberbrick-cloud-demo -n 30 --no-pager'
```

未绑定时页面会显示独立云端虚拟设备的 6 位激活码；在[灵矽智控台](https://xrobo.qiniu.com/)的相应智能体「设备管理」添加设备并填入激活码。当前设备已绑定且服务端观察到平台握手；页面连接成功后可点「启用语音」并允许麦克风权限，按住「按住说话」发话，松开发送静音等待回复。页面同时只允许一位控制者，已有控制者时不要抢占；灵矽文字转写和回复也可能出现在服务器服务日志中。这里用的是云端新建的虚拟设备，不会覆盖电脑上的原身份；当前工具只操作模拟小车。
