# 运行说明

从零开始，到对着小车说话让它动起来。架构见 [架构设计](架构设计.md)。

## 1. 准备

| 需要 | 说明 |
|---|---|
| 电脑 | macOS / Windows / Linux，Python ≥ 3.11，有麦克风和扬声器（建议戴耳机，防止小车的声音被自己听到） |
| 小车 | CyberBrick Mini T（Core = ESP32-C3），充好电 |
| 灵矽账号 | 智控台 <https://xrobo.qiniu.com/>，创建一个智能体 |
| 2.4G Wi-Fi | 电脑和小车连同一个网络（手机热点也行） |
| 手机（可选） | 当俯拍摄像头用（装 IP Webcam 一类的 App），绕杯子一圈时需要 |

```bash
git clone git@github.com:tibelf/cyberbrick-linxi.git
cd cyberbrick-linxi/linx-client
python -m venv .venv && source .venv/bin/activate   # Windows：.venv\Scripts\activate
pip install -r requirements-dev.txt                  # 运行依赖 + 测试
```

## 2. 配置灵矽智能体（只做一次）

在智控台打开你的智能体：

1. **意图识别**选「意图识别与聊天使用同一模型（Function Call）」，模型要支持工具调用。不选这一项，大模型不会调用小车的工具。
2. **角色介绍**粘贴 [`linx-client/prompts/agent-prompt.md`](../linx-client/prompts/agent-prompt.md) 的全部内容。
3. **对话与视觉 → 视觉分析**打开并选一个视觉模型（绕杯子一圈拍俯拍图要用）。
4. 保存。以后每次改配置，都要重启下面的程序才生效。

## 3. 激活虚拟设备（只做一次）

```bash
python -m linx_client activate
```

终端会打印 6 位激活码。到智控台「智能体 → 设备管理 → 添加设备」输入这个码，绑定成功后程序自动退出。

设备身份保存在 `.linx_device.json`。**不要删除，也不要提交到仓库**：平台只凭 Device-Id 认设备，泄露了别人就能冒充你的设备。

## 4. 先不接车，试一下

```bash
python -m linx_client run --backend mock --web
```

对着麦克风说「往前走两秒然后开一炮」，终端和网页 <http://localhost:8080> 会依次出现：你说的话、`移动 direction=forward duration_ms=2000`、`开火 shots=1`、小车的语音回复。mock 模式只打印，不会动车。

不方便说话时，在终端输入 `t 往前走两秒` 发文字。

## 5. 给车装 Wi-Fi 控车程序（只做一次）

用 USB 线把**车上的** Core 连到电脑：

```bash
python -m linx_client wifi-setup
```

按提示输入车要连的 2.4G Wi-Fi（可以填多个），再设一个 8–9 位的维护密码（保存在 `.car_admin_password`，不进仓库）。装完车会重启，看 Core 上的灯：

| 灯 | 含义 |
|---|---|
| 黄 | 正在连 Wi-Fi |
| 蓝 | 已连上，可以拔 USB 了 |
| 紫 | 没连上，车自己开了热点 `CyberBrick-Tank`（电脑连这个热点，车的地址是 192.168.4.1） |

以后改了车端程序，不用插线也能更新：`python -m linx_client wifi-setup --host <车的IP> --code-only`。想恢复原厂遥控：`wifi-setup --uninstall`。


## 6. 正式运行

**基础版**（除了“绕杯子一圈”，其他场景都能用）：

```bash
python -m linx_client run --backend udp --web
```

- `--camera`：手机 IP Webcam 的 JPEG 快照地址；也可以填 `0` 用电脑摄像头。
- `--blind`：开启闭眼导航（拍一张俯拍图规划，之后不拍照走完）。
- `--blind-cm-per-s`：车直行速度（厘米/秒。
- 想用手机当遥控手柄，再加 `--pad`，扫网页上的二维码。

**随时急停**：说「停」、终端直接回车、网页上的红色急停按钮、键盘 Esc，任何一个都行。

## 7. 演示脚本

| 功能 | 对小车说 | 预期 |
|---|---|---|
| 场景 1：发射炮弹 | “开一炮” | 扣扳机发射 1 发（每次最多 3 发，间隔 1.5 秒） |
| 场景 1：绕杯子一圈 | “拍一张俯拍图”→“绕着杯子转一圈” | 拍一次照，规划路线，绕杯子一圈回到出发点（需要完整版命令） |
| 场景 2：跳舞 | “跳个舞” | 原地左右扭两下，炮管上下点头 |
| 场景 3：全军出击 | 先教一次：“记住，全军出击就是全速前进 5 秒，重复 8 次”；之后：“执行全军出击” | 满速前进共 40 秒，说“停”随时停下。动作宏保存在本机，教一次以后一直可用。**需要足够长的空场地** |
| 场景 4：闲逛 | “自己逛逛” | 随机方向和距离到处走，前方堵住就转向；说“停”才结束，闲逛中绝不开火 |
| 场景 5：老爷爷模式 | “切换成老爷爷模式”→“往前走三秒” | 说话慢悠悠，走一会歇一会 |
| 恢复 | “恢复正常” | 退出老爷爷模式 |

老爷爷模式会一直保持到说“恢复正常”，可以和闲逛叠加，就是慢悠悠地逛。
