**新增功能已部署（实测进度见交接看板）**：网页补充炮管每次 200 ms 的上/下微调、启用/锁定发射及单发。默认锁定；服务端须加 `--allow-fire` 且车端报告 `fire-v1` 才能启用。每次点击单发，冷却期间拒绝重复点击；现有语音炮管/发射工具使用同一启用状态。停车、页面断线或切后台会重新锁定。卸弹架空测试已收到两次炮台调整和一次空载扳机的设备成功应答，用户确认「炮台上下都有动作，扳机也动了」；本轮未测试有弹发射。

## 使用与恢复

1. 打开手机 2.4 GHz 热点，打开小车电源。当前热点已保存在车上，主控开机后自动连接云端。
   小车关机不会清除热点及云端配置；再次开机会自动读取并尝试连接，无需接电脑。热点名称和密码需与保存的一致，且能上网；暂时连不上时程序会继续重试。网页若自身也断开了，需在网页重新点「连接」。此前已验证主控复位自动上线和拔 USB 后运行，完整关闭电池电源再开机尚未由用户确认。
2. 手机打开 [腾讯云控制台](https://110.40.227.30/)，使用原来的浏览器账号密码登录，再用同一控制密码连接网页；密码不要提交仓库或发到聊天。
3. 首次测试先卸弹、架空，确认网页显示「真实小车在线」，按住方向键，松开应停车。语音点「点击开始说话」并允许麦克风，按钮变红后开始说话；计时与音量条反映收音，再点「结束说话」停止录音，无需长按。录音实时上传，平台可能在结束录音前开始回复或执行已识别的指令。当前速度上限为 40，履带落地后能否带动车尚未验证。
4. 炮台点「抬高一点 / 压低一点」短暂微调。点「启用发射」后可点「发射一发」，也可说「发射一发」；语音抬高/压低同样调用炮管工具。单发按钮冷却约 2 秒；执行结果仍以实车动作和错误提示为准，「已安排」只表示进入排程。
5. 若要回原厂遥控，在开机时按住主控板的 Pin 9 板载按键。云端模式不启动原 Wi-Fi UDP 及维护接口；需要改车端配置或卸载时通过 USB 维护。安装前的启动文件备份在车端 `/boot.pre-cloud-20261101.py`；`wifi-setup --uninstall` 通过 USB 恢复原厂并删除云端配置。

## 实现和约束

- 网页与云端服务走 HTTPS/WSS，用户连接需原有网页登录及控制密码；灵矽虚拟设备仍运行在腾讯云。火山云使用同一灵矽身份，不能同时启动。
- 车主动通过 WSS 连接 Nginx 的设备入口，服务器应用仅监听回环地址；车上使用私有 CA、`CERT_REQUIRED` 和服务名校验，并使用独立随机设备口令认证。设备证书有效性需要校时，当前小车通过 NTP 同步时间。实测正确证书通过，错误 CA 和错误服务名被拒绝。
- `cloud_car.py` 只在设备轮询时下发动作；服务端丢弃排队超过 400 ms 的指令，车端拒绝轮询往返超过 800 ms 的动作并检查编号与参数。断线时车端尝试停车，电机由硬件看门狗兜底；断线和弱网情况下的实际停车效果仍待实车验证。
- 云端 `TankExecutor` 保留队列、时长和限速约束；手机页面使用定期租约确认控制者在线。发射需当前控制者主动启用，backend 执行时再次检查；车端独立限制发射脉冲 ≤500 ms、脉冲后冷却 1500 ms，重连不清除冷却。车端还独立限制履带速度为 40。
- 车端启动时若存在 `/cloud.json` 和 `/wifi.json`，进入 `/app/cloud_main.py`；否则沿用局域网或原厂遥控的启动路径。配置中的口令及私有密钥不得写入仓库或终端日志。

腾讯云保留切换前的应用备份 `/var/backups/cyberbrick-real-0V1C5ko9/`；当前实车服务由 `cyberbrick-cloud-demo` 及其 systemd drop-in 启动。HTTPS 网页 IP 证书为短期证书，已配置续期定时器，但未来续期仍需观察。

## 网页打不开时

2026-11-01 在 Mac Chrome 复现过 `ERR_CONNECTION_CLOSED`：服务器 HTTPS 直连及证书正常，经当时的系统代理连接失败。为小车服务器地址添加系统代理直连例外后，Chrome 已恢复。若再次发生，分别检查服务器、直连和代理路径，勿仅凭网络错误关闭证书验证或网页鉴权。手机需核对自身网络，电脑上的代理配置不会修复手机网络。
