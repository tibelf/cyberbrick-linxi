# CyberBrick · Android 遥控器

这是一套使用 claude-design 制作的可编辑界面与交互设计，尚未生成 Android 工程或 APK。

## 设计范围

- `Main.dc.html`：默认锁定的遥控主页，含按住移动／松手停车、语音入口、炮台微调与发射入口。
- `Voice.dc.html`：收音、识别、回复示例及停车状态。为了呈现录音反馈，该画板初始展示收音场景；正式 App 应在用户主动点击并授予麦克风权限后才开始录音。
- `Fire.dc.html`：从「启用发射」进入的就绪场景，含单发、两秒冷却、手动锁定与急停。
- `Connect.dc.html`：原生连接表单与云端／小车／灵矽三个状态。控制密码保持空白，无实际凭据。
- `Offline.dc.html`：云端仍可用但小车离线的场景，含电源、热点检查与重新检查的反馈，不把离线写成「已确认停车」。

画板均为 390 × 844。底部导航链接连接三个主要页面；点击主页「启用发射」进入单发画板，连接页的离线帮助进入离线画板。每个画板的演示状态独立，不是一个已接入后端的 App。

## 视觉与使用

沿用实物灰黑车身和黄色履带轮的配色，使用石墨色底、黄色主操作及浅红停车控件。输入框、按钮和导航采用清晰的触控尺度，保留系统顶部空间，不绘制虚假的状态栏、键盘、电量或网络延迟。

在编辑器中可修改文字、颜色、间距与布局；Tweaks 提供跨界面的主色调整。进入 Play 可试点导航、按键反馈、语音状态切换、单发冷却和连接状态示例。使用前无须输入真实密码。

## 与现有程序的关系

所有连接、录音、回复及动作都是界面示例。此原型没有云端、麦克风或控车网络请求，不会产生真实车辆动作，也不表示新增手机操作已完成实车验收。摄像头继续暂停，不绘制画面占位。

原生实现应继续使用现有手机 → 腾讯云 → 小车路径，保留按键租约、动作过期拒绝、松手停车和发射锁定／冷却。App 统一处理网页登录及控制通道认证，让使用者只填写一次连接信息；灵矽设备身份继续留在云端，不复制到 App 或设计稿。

## 当前验证范围

仅使用本技能的 `artifact.mjs check` 检查文件与格式。没有运行浏览器、截图、渲染或原生 App 测试；动态交互与视觉布局仍供用户在编辑器中评审。
